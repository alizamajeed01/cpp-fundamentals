# C++ Fundamentals

This repository contains my C++ learning journey and practice programs.
It includes concept-based programs covering fundamental C++ topics and
Object-Oriented Programming (OOP).

### Basic C++ Concepts

- Loops
- Functions
- Recursion
- Arrays and Functions
- Call by Value
- Call by Reference
- Pointers
- Pointer Arithmetic
- Static Memory Allocation
- Dynamic Memory Allocation
- Vectors
- Prevention of Memory Leaks

### Object-Oriented Programming (OOP)

- Classes and Objects
- Access Specifiers
- Constructors
  - Default Constructor
  - Parameterized Constructor
  - Copy Constructor
  - Default Copying
- Destructors
- Friend Class
- Friend Function
- Static Members and Static Functions

### Inheritance

- Inheritance
- Single Inheritance
- Multiple Inheritance

### Polymorphism

- Function Overloading
- Operator Overloading
- Function Overriding
- Virtual Functions
- Runtime Polymorphism
- "final" Keyword

## Purpose

The purpose of this repository is to practice C++ concepts through
small, focused programs and to build a strong foundation in C++ and OOP.

Each C++ file demonstrates a particular concept or example.
